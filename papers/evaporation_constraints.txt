# Hawking evaporation constraints on light compact objects
#
# Transcribed from the cited publications on 2026-09-29. Used to bound the
# relic mass. All values are observed upper limits on the fraction of dark
# matter, not theoretical expectations.
#
# THE RELEVANT SCALE
#
# Hawking evaporation rate  dM/dt = -B/M^2  with
#   B = hbar c^4 / (15360 pi G^2)  = 3.9636e15 kg^3/s
# so a compact object of mass M has an evaporation lifetime
#   tau = M^3 / (3B)
# The evaporation horizon is the mass whose lifetime equals the age of the
# universe (4.35e17 s):
#   M_eh = (3 B t_univ)^(1/3) = 1.7294e11 kg = 1.7294e14 g = 7.9477e18 M_Pl
#
# Objects above M_eh have NOT had time to evaporate. Objects below it would
# have emitted their remaining mass as radiation, and that radiation has been
# searched for directly.

== VOYAGER1 ==

Voyager 1 e+/e- spectra, beyond the heliopause, constraining Hawking emission
from compact objects below the evaporation horizon.

mass_limit_g = 1e16          # g, below which the limit applies
f_pbh_limit = 0.001          # fraction of Galactic dark matter, 95% CL
reference = Boudaud, M. & Cirelli, M. "Voyager 1 further constrain primordial
           black holes as dark matter." Phys. Rev. Lett. 122, 041104 (2019).
           Local Galactic measurement, so complementary to cosmological bounds.

== AMS02 ==

AMS-02 positron fraction and electron+positron flux, with diffusive
reacceleration transporting sub-GeV evaporated particles into the measured
GeV range.

mass_limit_g = 1e16          # g, characteristic constrained mass
f_pbh_limit = 0.1            # fraction of dark matter, 95% CL
reference = Su, B.-Y. "Constraining primordial black holes as dark matter
           using AMS-02 data." Eur. Phys. J. C (2024).
           Extends sensitivity below 1e15 g by up to an order of magnitude
           relative to Voyager 1.

== INTEGRAL ==

INTEGRAL detection of the Large Magellanic Cloud provides one of the
strongest soft gamma-ray bounds on evaporation from compact objects
below the evaporation horizon.

f_pbh_limit = 0.001          # order-of-magnitude bound, LMC 511 keV line
reference = "Updated constraints on primordial black hole evaporation."
           J. Phys. Conf. Ser. (2023). Reconsiders 511 keV line constraints
           from diffuse Galactic soft gamma emission and the isotropic soft
           gamma background.

## Note on use

These are the only empirical handles on whether evaporation stops. The
corpus previously carried a relic mass of 1e-5 M_Pl = 2.176e-10 g with no
source. That value lies 7.9e23 below the evaporation horizon, in a mass range
where the measurements above limit any surviving population to under 0.1% of
dark matter, and to 0.1% at Voyager sensitivities.

The bound applies to objects whose mass loss proceeds by Hawking radiation.
A relic whose emission is arrested by the field is not subject to it, but it
is subject to the abundance requirement: a population limited to 0.1% cannot
supply Omega_relic = 0.27.

These values are read by relic_abundance.py.
