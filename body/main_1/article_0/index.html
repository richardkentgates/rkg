Metamanager v2.3.117 + v2.4.57

Complete metadata management for WordPress. The WordPress plugin handles Schema.org structured data for 10+ types, Open Graph, XML & HTML sitemaps, robots.txt, link checker, breadcrumb labels, business profile, and author profiles. The OS-level daemons handle lossless image/video/audio compression and bidirectional EXIF/IPTC/XMP metadata embedding — all outside of PHP so WordPress never blocks.
